# 🌡️ Time Series Data Analysis

This time-series analysis project investigates long-term temperature trends and seasonal shifts in Seoul, South Korea, using long-term daily observation records. It analyzes changes in extreme heat days (≥35°C), asymmetric temperature trends between summer and winter, and seasonal transition shifts, while using Linear Regression and ARIMA to forecast Seoul's average summer temperatures for the next five years. Furthermore, the analysis results are deployed as an interactive Streamlit dashboard, enabling users to explore findings dynamically across customizable date ranges and conditions.

* Analysis Report: [REPORT.md](REPORT.md)

## 📖 Project Overview

* **Topic:** Identification of long-term warming trends, diagnosis of seasonal expansion/contraction patterns, and forecasting of average summer temperatures for the next 5 years (2026–2030) through time-series analysis of daily observed temperatures in Seoul from 1907 to 2026.
* **Dataset:** Korea Meteorological Administration (KMA) Weather Data Service – Automated Synoptic Observing System (ASOS) daily temperature records from Seoul Weather Station (Station ID 108, Songwol-dong) (Total 42,236 records).
* **Key Objectives:** 
  - Quantitatively determine long-term temperature rise rates based on over 100 years of continuous public meteorological time-series data.
  - Verify and compare the asymmetric warming rates between summer and winter.
  - Diagnose practical summer expansion and winter contraction (Seasonal Boundary Shift) patterns by analyzing temperature characteristics during transition months (May & September, November & March).
  - Forecast Seoul's average summer temperatures for the next 5 years (2026–2030) with 95% confidence intervals using ARIMA(0,1,1) and Linear Regression models.

## 🔄 Data Analysis Pipeline & Execution Order

This project consists of a 6-stage modular pipeline, spanning from raw data ingestion to final web service deployment:

1. **Data Ingestion, Cleaning & Preprocessing (`1_EDA_preprocessing.ipynb`):**
   - Standardization of date formats and extraction of derived variables (`season`, `summer_like`, `winter_like`, `over_35`, etc.).
   - 1.5×IQR-based outlier detection and exclusion of the Korean War missing period (1950–1953) from artificial interpolation.
2. **Descriptive Statistics & Time-Series Aggregation (`2_descriptive_analysis.ipynb`):**
   - Aggregation of annual mean/max/min temperatures, seasonal mean temperatures, and extreme heat (≥35°C) days.
3. **Long-Term Trend Statistical Analysis (`3_trend_analysis.ipynb`):**
   - Identification of baseline warming trends using 10-year moving averages.
   - OLS Linear Regression, non-parametric Mann-Kendall trend tests, and Sen's Slope estimation.
4. **Seasonal Boundary Shift Analysis (`4_seasonal_expansion_analysis.ipynb`):**
   - Trend analysis of transition-month proportions (May, September, November, March) based on daily mean thresholds: ≥20°C ("summer-like days") and ≤5°C ("winter-like days") (early/extended summer in May/September; contracted winter in March/November).
5. **Summer Temperature Forecasting (`5_prediction.ipynb`):**
   - Stationarity verification via ADF unit root test followed by ARIMA(0,1,1) and linear regression modeling.
   - Backtesting evaluation (MAE/RMSE) over the past 5 years and 95% prediction interval estimation for 2026–2030.
6. **Productization & Reporting (`app.py` / `REPORT.md`):**
   - Interactive Streamlit web dashboard built with Plotly, alongside the comprehensive analysis report.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone git@github.com:freepoincare/time-series-data-analysis.git
cd time-series-data-analysis
```

### 2. Environment Setup & Dependency Installation

```bash
# Create and activate virtual environment (optional)
python -m venv .venv

# macOS/Linux:
source .venv/bin/activate

# Windows PowerShell:
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 3. Run the End-to-End Analysis Pipeline

Execute the full workflow from raw data preprocessing through statistical analysis to chart generation in a single command:

```bash
python analysis.py
```
> Upon completion, processed datasets (`data/processed/*.csv`) and figure images (`images/plots/*.png`) are automatically generated.

Alternatively, open each Jupyter Notebook and click [Run All] at the top or execute cells step by step.

## 📊 Interactive Web Dashboard (Streamlit)

A responsive web dashboard allowing users to explore the 118-year Seoul temperature time-series analysis in real time by customizing date ranges and filter conditions.

* Dashboard Link: [seoul-temperature-analysis.streamlit.app](https://seoul-temperature-analysis.streamlit.app/)

### 🌟 Key Features
1. **Interactive Controls:**
   - **Year Range Slider (1907–2026):** Dynamically set past time windows to recompute statistics and re-render charts in real time.
   - **Temperature Metric Toggles:** Select and compare annual mean, minimum, and maximum temperatures.
   - **Season/Month Selection Filters:** Examine ratio changes across transition months (May, September, March, November), heatmaps, and 28-year epoch comparisons (1908–1935 vs. 1998–2025).
   - **Forecast Model Comparison:** Interactively toggle between ARIMA(0,1,1) and linear regression forecasts and their 95% confidence intervals.
2. **Plotly Interactive Visualizations:**
   - Rich hover tooltips displaying year, month, temperature, percentage (%), etc.
   - Zoom, pan, and legend toggling for isolating individual series.
3. **Single Expandable Core Question Accordions:**
   - In the Dashboard Overview tab, clicking any of the 6 core research question cards expands its statistical findings and conclusions in a responsive UI.

### 🖥️ Local Execution

(Requires Streamlit installation)
```bash
streamlit run app.py
```
> Upon execution, your browser will open automatically, allowing you to explore the dashboard at `http://localhost:8501`.
