# 시계열 데이터 분석 기법

시계열 데이터 분석 기법은 시간에 따라 순차적으로 기록된 데이터에서 의미 있는 통계적 특성을 추출하고, 이를 바탕으로 미래를 예측하거나 이상 징후를 탐지하는 방법. 분석 목적(전처리, 패턴 분석, 미래 예측)에 따라 최적의 기법을 조합하여 사용.

---

## 🛠️ 1. 데이터 전처리 및 피처 엔지니어링 (Data Preprocessing)

시계열 데이터는 연속성이 중요하므로, 일반 데이터와 다른 특수한 전처리가 필요.

* 결측치 처리 (Missing Values): 행을 삭제하면 시간 흐름이 끊기므로, 직전 값으로 채우는 전방 채우기(Forward Fill), 다음 값으로 채우는 후방 채우기(Backward Fill), 또는 선형 보간법(Interpolation)을 사용.
* 정상성 변환 (Stationarity): 많은 전통 통계 모델은 평균과 분산이 일정한 '정상성'을 요구합니다. 이를 위해 현재 값에서 이전 값을 빼는 차분(Differencing)이나 로그 변환을 적용.
* 이동 변환 및 지연 피처 (Lag & Window): 과거 시점의 데이터 변동을 반영하기 위해 지연 변수(Lagged Variables, $Y_{t-1}$)나 특정 기간의 평균을 구하는 이동 평균(Rolling Mean) 피처를 생성합니다.

---

## 🔎 2. 데이터 탐색 및 시계열 분해 (Decomposition)

시계열 데이터의 내재된 패턴을 시각화하고 구조적으로 분리하는 단계.

* 고전적 시계열 분해: 데이터를 추세(Trend, 장기 변동), 계절성(Seasonality, 주기적 반복), 잔차/불규칙 요인(Residual/Noise, 무작위 변동)의 3가지 요소로 쪼개어 분석.
* 자기상관 분석 (Autocorrelation): ACF(자기상관함수) 및 PACF(부분자기상관함수) 그래프를 그려 현재 데이터가 과거의 어느 시점(Lag)과 가장 강하게 연결되어 있는지 확인합니다.

---

## 📊 3. 전통 통계학적 예측 모델 (Statistical Models)

수학적 규칙성을 기반으로 하며, 데이터가 비교적 적고 직관적인 해석이 필요할 때 유용.

* 지수평활법 (Exponential Smoothing, ETS): 오래된 데이터보다 최근 데이터에 더 높은 가중치를 부여하여 예측합니다. 추세와 계절성을 모두 반영할 수 있는 홀트-윈터스(Holt-Winters) 기법이 대표적.
* ARIMA (AutoRegressive Integrated Moving Average): 시계열 예측의 표준 모델. 과거 자기 자신의 값(AR), 데이터의 정상화(I, 차분), 과거의 예측 오차(MA)를 종합하여 미래를 계산.
* SARIMA: ARIMA에 계절성(Seasonal) 요소를 추가하여 매월 또는 매년 반복되는 주기적 패턴을 지닌 데이터 분석에 특화된 모델.
* VAR (Vector Autoregression): 여러 시계열 변수가 서로 영향을 주고받는 다변량 상황(예: 마케팅 비용, 웹사이트 방문자 수, 매출의 상호 관계)을 분석할 때 사용.

---

## 🚀 4. 머신러닝 및 딥러닝 모델 (ML / Deep Learning)

데이터의 양이 방대하고 변수 간의 비선형적이고 복잡한 관계를 학습해야 할 때 사용.

* Prophet: Meta(페이스북)에서 개발한 오픈소스 라이브러리. 분석 지식이 부족해도 결측치, 대규모 이상치, 휴일 효과(명절, 공휴일 등)를 자동으로 처리해 주어 비즈니스 예측에 널리 쓰임.
* 트리 기반 앙상블: XGBoost, LightGBM, Random Forest 같은 머신러닝 모델에 시간 지연(Lag) 변수와 날짜/시간 피처를 입력하여 시계열 예측을 수행.
* LSTM (Long Short-Term Memory): 시계열에 특화된 순환신경망(RNN)의 일종으로, 긴 시계열 데이터의 장기 의존성과 맥락을 기억하고 학습하는 데 뛰어난 성능을 보임.
* 트랜스포머 (Transformers): 자연어 처리에 쓰이는 어텐션(Attention) 메커니즘을 시계열에 도입한 기법(TFT, Informer 등)으로, 매우 긴 기간의 패턴을 동시에 병렬로 분석할 수 있음.

## 💡 핵심 기법 비교 요약

| 기법 카테고리 | 주요 용도 | 장점 | 단점 |
|---|---|---|---|
| 이동평균 (Moving Average) / 지수평활 | 단기 예측, 데이터 스무딩 | 직관적이고 연산이 매우 빠름 | 급격한 트렌드 변화 반영 부족 |
| ARIMA / SARIMA | 선형 패턴을 가진 시계열 예측 | 통계학적 신뢰도 및 해석력 높음 | 전문가의 수동 파라미터 튜닝 필요 |
| Prophet | 비즈니스 지표, 이벤트 반영 예측 | 자동화 기능 우수, 이상치에 강함 | 불규칙한 미세 변동 오버피팅 위험 |
| 딥러닝 (LSTM 등) | 대용량 데이터, 복잡한 패턴 학습 | 가장 높은 예측 잠재력 보유 | 대량의 데이터 필요, 내부 해석 어려움 |
