## 선형 회귀 분석 (Linear Regression) 요약
선형 회귀 분석은 독립변수($X$)와 종속변수($Y$) 간의 선형적(직선) 상관관계를 수학적 모델로 공식화하여, 새로운 $X$ 값이 주어졌을 때 $Y$ 값을 예측하고 변수 간의 인과관계를 설명하는 통계 기법입니다.
------------------------------
## 1. 기본 수식 모델## ① 단순 선형 회귀 (Simple Linear Regression)
독립변수가 1개일 때 사용합니다.
$$Y = \beta_0 + \beta_1 X + \epsilon$$ 

* $Y$: 종속변수 (예측하고자 하는 결과값 / 반응변수)
* $X$: 독립변수 (원인이 되는 값 / 설명변수)
* $\beta_0$: $Y$절편 (상수항)
* $\beta_1$: 회귀 계수 (기울기, $X$가 1단위 변할 때 $Y$의 변화량)
* $\epsilon$: 오차항 (모델이 설명하지 못하는 무작위 노이즈)

## ② 다중 선형 회귀 (Multiple Linear Regression)
독립변수가 2개 이상일 때 사용합니다.
$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_k X_k + \epsilon$$ 
------------------------------
## 2. 핵심 학습 원리: 최소제곱법 (OLS, Ordinary Least Squares)
회귀 분석은 실제 데이터 포인트들과 회귀 직선 간의 거리의 제곱 합(SSE, Sum of Squared Errors)을 최소화하는 직선을 찾는 방식으로 작동합니다.
$$\text{Minimize} \sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2$$ 

* $Y_i$: 실제 관측값
* $\hat{Y}_i$: 모델이 예측한 값 ($\beta_0 + \beta_1 X_i$)

------------------------------
## 3. 선형 회귀의 4대 기본 가정
모델의 통계적 유효성을 확보하기 위해 오차항($\epsilon$)이 반드시 만족해야 하는 4가지 조건입니다. 이 가정이 깨지면 모델의 예측력을 신뢰할 수 없습니다.

* 선형성 (Linearity): 독립변수와 종속변수 간의 관계가 직선 형태여야 합니다.
* 독립성 (Independence): 오차항끼리 서로 상관관계가 없어야 합니다. (시계열 데이터에서 이동평균 처리 시 이 가정이 잘 깨집니다.)
* 등분산성 (Homoscedasticity): 모든 $X$ 값 영역에서 오차의 분산이 일정해야 합니다.
* 정규성 (Normality): 오차항의 분포가 평균이 0인 정규분포를 따라야 합니다.

------------------------------
## 4. 모델 성능 평가 지표

* 결정계수 ($R^2$, R-Squared):
* 모델이 전체 데이터의 변동성을 얼마나 잘 설명하는지 나타내는 지표 (0 ~ 1 사이 값).
   * 1에 가까울수록 설명력이 높은 모델입니다.
* 조정된 결정계수 (Adjusted $R^2$):
* 다중 회귀에서 불필요한 변수가 추가될 때 $R^2$가 무조건 상승하는 단점을 보완한 지표입니다. 변수의 개수에 패널티를 부여합니다.
* 평가 오차 지표: MAE (평균 절대 오차), MSE (평균 제곱 오차), RMSE (평균 제곱근 오차) 등이 있으며, 값이 작을수록 예측 성능이 좋습니다.
