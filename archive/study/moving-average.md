## 시계열에서 이동평균(Moving Average, MA) 수식
시계열 분석에서 이동평균은 크게 데이터를 부드럽게 만드는 필터(Smoothing) 수식과 ARIMA 모델 내부의 예측(Stochastic Process) 수식 두 가지로 나뉩니다. 두 수식은 목적과 형태가 완전히 다릅니다.
------------------------------
## 1. 데이터 평활용 이동평균 수식 (Smoothing Filter)
과거와 현재의 실제 관측값($Y_t$)을 평균 내어 노이즈를 제거하는 수식입니다. 보통 단순이동평균(SMA)과 지수이동평균(EMA)을 가장 많이 씁니다.
## ① 단순 이동평균 (Simple Moving Average, SMA)
가장 직관적인 방식으로, 정해진 윈도우 크기($k$)만큼의 최근 데이터를 산술 평균 냅니다.

* 최근 $k$개 데이터를 사용하는 수식 (매끄러운 예측용):
$$M_t = \frac{Y_t + Y_{t-1} + Y_{t-2} + \dots + Y_{t-k+1}}{k} = \frac{1}{k} \sum_{i=0}^{k-1} Y_{t-i}$$ 
* 중심 이동평균 수식 (시계열 분해용):
현재 시점 전후의 데이터를 모두 사용하여 추세를 잡을 때 씁니다.
$$M_t = \frac{1}{2m+1} \sum_{j=-m}^{m} Y_{t+j}$$ 

## ② 지수 이동평균 (Exponential Moving Average, EMA)
최근 데이터에 더 높은 가중치($\alpha$)를 부여하고, 과거로 갈수록 가중치가 지수적으로 감소하는 수식입니다. 데이터의 최근 변화를 더 빠르게 반영합니다.
$$M_t = \alpha Y_t + (1 - \alpha) M_{t-1}$$ 

* $\alpha$: 평활 상수 ($0 < \alpha \le 1$, 보통 $\frac{2}{k+1}$ 사용)
* $Y_t$: 현재 시점의 실제 관측값
* $M_{t-1}$: 직전 시점의 지수 이동평균값

------------------------------
## 2. ARIMA 모델 내부의 MA($q$) 수식 (Stochastic Process)
ARIMA 같은 확률 모형에서의 MA 수식은 관측값이 아니라, 과거 시점들의 '예측 오차(Residual/Noise)'를 가중합하여 현재 값을 예측하는 수식입니다.
## 📌 MA($q$) 모델 공식
$$Y_t = \mu + \epsilon_t + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + \dots + \theta_q \epsilon_{t-q}$$ 

* $Y_t$: 현재 시점의 시계열 값
* $\mu$: 시계열의 평균(상수항)
* $\epsilon_t$: 현재 시점의 백색 잡음(White Noise) 혹은 현재 오차
* $\epsilon_{t-1}, \dots, \epsilon_{t-q}$: 과거 $q$개 시점의 예측 오차
* $\theta_1, \dots, \theta_q$: 오차에 곱해지는 MA 가중치 계수

------------------------------
## 💡 두 수식의 핵심 차이점 요약

| 구분 | 데이터 평활용 MA (SMA/EMA) | ARIMA 모델의 MA($q$) |
|---|---|---|
| 계산 대상 | 실제 데이터의 관측값($Y_t$)을 평균 냄 | 모델이 틀린 오차값($\epsilon_t$)을 평균 냄 |
| 가중치($\theta, \alpha$) | 사용자가 고정 (예: 다 똑같이 $\frac{1}{k}$ 또는 $\alpha$) | 데이터 학습을 통해 최적의 가중치를 추정 |
| 목적 | 그래프를 부드럽게 만들어 추세 파악 | 과거의 충격(오차)이 현재에 미치는 예측력 강화 |
