# Null hypothesis

p-value < 0.05 → generally reject the null hypothesis.

Key Concepts:

* Null Hypothesis (H₀): The default assumption that there is no effect, no difference, or no relationship in your data.
* Significance Level (α): The threshold set before the test, commonly 0.05 (5%), which controls your risk of a false positive.
* Decision Rule: If p ≤ α (or p < 0.05), the result is statistically significant, and you reject H₀. If p > 0.05, you fail to reject H₀.
